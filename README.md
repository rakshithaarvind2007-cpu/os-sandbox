## Deploy to GitHub Pages

The web app deploys automatically when changes are pushed to `main`.

1. In the repository on GitHub, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
2. Merge the app changes into `main`, or run the **Deploy Flutter web to GitHub Pages** workflow from the **Actions** tab.
3. Once the workflow completes, open <https://rakshithaarvind2007-cpu.github.io/os-sandbox/>.

The workflow builds Flutter for the repository subpath, uploads `build/web`, and publishes it with GitHub Pages.
